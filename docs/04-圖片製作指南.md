# 04 — 圖片製作指南

> 分工：**我寫提示詞，你產圖。** 我沒有直接產生點陣圖的能力，但我會把提示詞寫到你可以直接複製貼上。

---

## ★ 比例與安全區（最重要的一節）

### 問題

平板橫向約 **4:3**，手機直向約 **9:19.5**。同一張圖不可能在兩邊都完美填滿。

- 用 `contain`（完整顯示）→ 手機直向上下會有大片空白，圖變得很小
- 用 `cover`（填滿裁切）→ 手機直向會把左右各切掉一大塊，主角可能被切一半

### 解法

> **產 4:3 橫式圖，但構圖時把主體放在中央的 1:1 正方形安全區內。**

```
        ← 1600 px（4:3 橫式）→
   ┌────────┬──────────────┬────────┐
   │        │              │        │   ↑
   │  可裁  │   1:1 安全區  │  可裁  │
   │  區    │              │  區    │  1200 px
   │        │   ★ 放主角    │        │
   │        │              │        │   ↓
   └────────┴──────────────┴────────┘
    200 px   ← 1200 px →    200 px
```

| 裝置 | CSS | 結果 |
|---|---|---|
| **平板橫向** | `object-fit: contain` | 整張 4:3 完整顯示，兩側用深色背景填滿 |
| **手機直向** | `object-fit: cover` | 裁切到接近 1:1，**主角完整保留** |

左右兩側的「可裁區」放背景、氛圍、次要元素 — 被切掉也不影響故事。

### 寫進提示詞的話術

每個場景提示詞都要包含：

```
main subject centered, all important elements within the central square area,
generous empty margins on the left and right sides
```

## 交付規格

| 項目 | 規格 |
|---|---|
| 比例 | **4:3 橫式** |
| 產圖尺寸 | 至少 1600×1200（越大越好，之後可以縮，不能放大） |
| 進 repo 的檔案 | 長邊 **1600 px**、**WebP 品質 80**、目標 **< 300 KB** |
| 每篇場景數 | 8–16 張（建議 **12**） |
| 封面 | 另外一張，同樣 4:3，要能一眼看出是哪個故事 |
| 檔名 | `cover.webp`、`01.webp` … `16.webp`（**兩位數補零**） |

### 建置時會自動產生（你不用管）

| 變體 | 用途 | 估計大小 |
|---|---|---|
| AVIF 480w | 手機 | ~25 KB |
| AVIF 960w | 平板 | ~70 KB |
| AVIF 1440w | 平板 Retina | ~130 KB |
| WebP 960w | 舊瀏覽器備援 | ~130 KB |
| AVIF 320w | 選單封面縮圖（僅 cover） | ~15 KB |

**每張圖的全部變體合計約 355 KB → 每篇故事約 4.6 MB。** 這個數字直接決定了容量風險，詳見 [06](./06-風險評估.md#風險-1網站容量撞到-1-gb-硬限制)。

### 壓縮

實作時會做成一支腳本（`npm run prepare-images <slug>`），內部大致是：

```bash
npx sharp-cli -i raw/01.png -o images/01.webp \
  resize 1600 --withoutEnlargement \
  -f webp -q 80
```

**原始大檔（PNG / 4K）不要 commit 進 repo。** 壓好再進版控 — git 歷史刪不掉，傳過一次就永遠在裡面（[見風險 2](./06-風險評估.md#風險-2repo-容量與-git-歷史膨脹)）。

## ★ 角色一致性工作流

### 最常見的失敗

12 張圖裡的小紅帽，有 12 種長相。孩子對角色外觀的敏感度比大人高很多 — 髮型變了他馬上會問「那是誰？」，故事就斷了。

### 三段式解法

#### 第 1 步：先產「角色設定表」

只畫角色，不畫場景。這一張是後面 12 張的基準。

```
character reference sheet, a 6-year-old girl named Little Red,
round face, big dark brown eyes, short black bob haircut with straight bangs,
bright red hooded cape, mustard yellow dress, white socks, brown leather shoes,
three views: front view, side view, three-quarter view,
plain light grey background, full body, neutral pose, no shadows,
{STYLE_TOKEN}
```

**不滿意就重產這一張。** 不要帶著不滿意的角色往下走 — 這一步省下的時間，後面會用 12 倍還回來。

#### 第 2 步：鎖定「風格字串」

每個故事有一組固定的風格描述，**一字不改地**附加在每一個提示詞後面。

```
{STYLE_TOKEN} =
soft children's picture book illustration, gouache texture,
warm muted color palette, gentle rounded shapes, soft diffused lighting,
no text, no letters, no watermark, 4:3 aspect ratio
```

風格字串一旦定下來，整篇故事都不要改。想換風格 → 整篇重產。

#### 第 3 步：場景提示詞 = 角色描述 + 場景 + 構圖 + 風格字串

```
{CHARACTER_DESC}, standing at the door of a small stone cottage,
holding a woven basket covered with a checkered cloth,
warm morning sunlight, garden with white daisies,

main subject centered, all important elements within the central square area,
generous empty margins on the left and right sides,

{STYLE_TOKEN}
```

其中 `{CHARACTER_DESC}` 是第 1 步裡那一整段角色描述，**每一張都完整重複**，不要簡寫成「the girl」。

### 依工具而異的額外做法

| 你的工具支援 | 做法 |
|---|---|
| **參考圖 / 角色參考**（Nano Banana、Midjourney `--cref`、Firefly） | 每一張都掛上第 1 步的設定表當參考圖 — **效果最好** |
| **固定 seed** | 整篇故事用同一個 seed |
| **都不支援** | 靠 `{CHARACTER_DESC}` 寫得夠具體（髮型、髮色、眼睛顏色、每一件衣服的顏色與材質），並在每張圖完整重複 |

> 建議的 Gemini 與 Midjourney 都屬於第一類（支援參考圖），所以照[建議路徑](#建議路徑)走的話，你會拿到效果最好的那一種工作流。

### 驗收

把 12 張圖並排看一次。**如果有一張的角色明顯不一樣，就重產那一張，不要將就。**

## 其他注意事項

### 不要在圖裡產生文字

AI 產生的中文字幾乎都是亂碼或錯字。所有文字一律由網頁疊上去。

提示詞固定加上：`no text, no letters, no watermark, no signature`

如果故事需要出現招牌、書本封面之類的東西，讓它變成**空白的**或**圖案化的**。

### 避免恐怖谷

用明確的兒童插畫風格，不要寫實人像。半寫實的兒童臉孔是最容易產生詭異感的區間。

### 深色場景要小心

睡前用深色介面，太暗的圖會糊成一團看不出內容。夜晚場景要有**明確的光源**：

```
moonlight from the upper left, warm lantern glow, light from a window
```

### 檢查文化適切性

AI 預設常產出西方臉孔與西方場景。如果故事設定在台灣或需要亞洲角色，要在提示詞裡明確指定（`Taiwanese`、`East Asian features`、`traditional Taiwanese street`），不能靠它自己猜。

### 情緒要看得出來

孩子讀圖先讀表情。角色的情緒要在提示詞裡明講：

```
her eyes wide with curiosity, mouth slightly open in surprise
his shoulders slumped, looking down at the ground, sad expression
```

## 授權與公開性

⚠ 這幾點跟 [06 風險 3](./06-風險評估.md#風險-3公開-repo-的內容隱私已決定接受) 直接相關。

- **repo 已決定公開** → 所有圖片全世界可見、可被搜尋引擎索引。這是已知並接受的取捨
- **確認你用的 AI 繪圖工具，其產出物是否允許公開發布**。大部分付費方案允許商用與公開，部分免費方案有限制 — 動工前查一次該工具的條款
- **不要用「畫成某個知名 IP 的風格」的提示詞**（迪士尼、宮崎駿、特定繪本作家的名字）。私下自用是一回事，放在公開網站上是另一回事
- 建議在網站頁尾註明**圖片為 AI 生成**

## 提示詞範本（可直接複製）

### 角色設定表

```
character reference sheet, {角色年齡與身份},
{臉型}, {眼睛顏色與大小}, {髮型髮色},
{衣服每一件的顏色與款式}, {鞋子},
three views: front view, side view, three-quarter view,
plain light grey background, full body, neutral pose, no shadows,
{STYLE_TOKEN}
```

### 場景

```
{CHARACTER_DESC},
{在做什麼}, {在哪裡}, {手上拿著什麼},
{表情與肢體}, {光線},

main subject centered, all important elements within the central square area,
generous empty margins on the left and right sides,

{STYLE_TOKEN}
```

### 封面

```
{CHARACTER_DESC},
{最能代表這個故事的一個畫面},
{光線}, inviting and warm composition,

main subject centered, all important elements within the central square area,
generous empty margins on the left and right sides,

{STYLE_TOKEN}
```
