## 階段 5：資產外部化（觸發式，不排程）

**這個階段不按時間做，按門檻做。**

### 觸發條件（任一成立）

```
故事數 ≥ 180 篇
或
du -sh dist/  超過 700 MB
```

### 要做的事

按 [06 風險 1 的遷移劇本](./06-風險評估.md#遷移劇本約半天)執行：

```

[ ] 綁自訂網域 img.你的網域.com
[ ] rclone sync 圖片上去
[ ] GitHub repo 加變數 PUBLIC_ASSET_BASE_URL
[ ] 建置腳本改成不輸出圖片到 dist/
[ ] push，驗證
```

### 驗收

```
[ ] dist/ 大小掉到 50 MB 以下
[ ] 線上圖片正常顯示，且來源是 img.你的網域.com
[ ] 建置時間明顯縮短
[ ] 離線收藏功能仍然正常（跨網域快取要驗證 CORS）
```

## 不要提前做的事

| 不要提前做 | 為什麼 |
|---|---|
| **階段 1 就做 PWA** | 會拖慢起步，而且沒有內容之前離線沒有意義 |
| **20 篇之前做搜尋** | 20 篇用捲的就找得到，做了也用不到 |
| **180 篇之前搬 R2** | 過度設計。但 ★ **一定要從第一天就用 `assetUrl()`** |
| **一開始就做動畫特效** | 先把「不會白屏」做到，那比任何動畫都重要 |
| **一開始就寫 20 篇故事** | 先寫 3 篇跑完整流程，你會發現 schema 要調整 —— 3 篇時調整很便宜，20 篇時很貴 |
